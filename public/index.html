What is real, what is simulated

  • Real: your recovery phrase (BIP39), key derivation (BIP32/BIP84), testnet addresses, balances and history (mempool.space testnet API), on-chain sends — built, signed and broadcast as real testnet transactions — and BOLT11 invoices (real encoding, signed).
  • Simulated: Lightning settlement. This MVP has no live Lightning node, so paying an invoice is simulated and labelled DEMO. The next iteration connects a real node (LND/CLN) or a non-custodial SDK. Demo mode also simulates an on-chain balance so you can try every flow without faucet coins.
  • Your keys never leave this browser. The server only proxies public blockchain data; it never sees your phrase or private keys.
